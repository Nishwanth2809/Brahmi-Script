# Brahmi Script Frontend

React + Vite frontend for the Brahmi Script Recognition project.

Run from this folder:

```bash
npm install
npm run dev
```

Deploy this folder on Vercel with:

```text
Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
```

Set `VITE_API_BASE_URL` in Vercel when the Flask API is hosted separately.

For full backend, model, and production setup instructions, see the root `README.md`.
